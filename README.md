# Stash Plugins

A collection of plugins for [Stash](https://stashapp.cc/).

This repository contains plugins developed and maintained by **ProudRykar**.

## Plugins

| Plugin | Description |
|---|---|
| [External ASS Subtitles](https://github.com/ProudRykar/external-ass-subtitles) | Renders external ASS/SSA subtitles next to Stash scene videos using JASSUB, with support for SRT and VTT subtitles. |
